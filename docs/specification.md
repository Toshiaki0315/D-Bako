# 仕様書 (Specification) - D-Bako (道具箱)

## 1. 基本要件
- **ターゲットOS**: macOS 
- **フレームワーク**: Tauri v2 (Rust + TypeScript/React)
- **リポジトリ**: https://github.com/Toshiaki0315/D-Bako.git

## 2. UI / レイアウト
- 1ページにつき「縦2列 × 横4列」のグリッドレイアウトを採用する。
- 1ページあたりの最大登録数は8個。
- ページネーション機能を備え、UI上でページを切り替えられること。
- ウィンドウタイトルは「道具箱」とする。

## 3. アプリケーション管理
- **最大登録数**: 10ページ × 8個 = 合計80個。
- **ページ設定**: 設定画面（または設定ファイル）から最大10ページまでページ数を増減できること。
- **永続化**: 登録されたアプリのパス、配置ページ、グリッド位置などの情報はローカルに保存し、次回起動時に復元されること。

## 4. ユーザーアクション
- **登録 (Drag & Drop)**: 
  - macOSのFinderから `.app` バンドルをランチャーの空きスロットにD&Dする。
  - D&Dされたアプリのパスを取得し、アイコン画像を抽出してスロットに表示する。
- **起動 (Click)**:
  - 登録されたアプリアイコンをクリックすると、該当のアプリケーションが起動する。

## 5. 非機能要件
- **テストカバレッジ**: ユニットテストカバレッジ 90% 以上。
- **パフォーマンス**: アイコンの抽出処理等でUIスレッドをブロックしないよう非同期処理を徹底する。
